## Welcome

Build OctoFit Tracker, a three-tier fitness application, by completing the steps in this exercise. The workspace includes a React and Vite frontend, an Express and TypeScript API, and MongoDB persistence.

## Having trouble? 🤷

Run the relevant backend or frontend tests from the step instructions, and check that MongoDB, the API, and Vite use ports `27017`, `8000`, and `5173` respectively. The browser reaches the API through the Vite `/api` proxy.
